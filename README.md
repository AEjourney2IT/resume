# Alan Escobar – Resume

**Live site:** https://aejourney2it.github.io/resume/

IT support resume site for Alan Escobar: Tier 1 MSP support, CompTIA Security+, ISC2 CC, and CompTIA A+ in progress.

## How it works

| File | Purpose |
| --- | --- |
| `resume.json` | All resume content (summary, skills, certifications, experience, projects, education). Edit this file to update the site. |
| `index.html` | Page layout and link-preview tags |
| `render.js` | Reads `resume.json` and fills in the page |
| `style.css` | Screen and print (PDF) styles |

The site is published with GitHub Pages from the `main` branch. Use the **Download PDF** button (or your browser's Print → Save as PDF) for a printable copy.
